# 界面速览

这页把常用入口放在一起，第一次使用可以照着点一遍。下面按顶栏、工具条和阅读视图说明每个按钮。

## 顶栏

- **使用指南**：打开这份说明和快捷键提示，不会离开当前笔记。
- **连接 AI**：查看 Codex、WorkBuddy 等 Agent 的接入状态，复制全局注册指令。
- **标志色**：切换强调色；选择会保存在当前浏览器或桌面窗口。
- **＋ 新建笔记**：打开编辑器。标题必填，分类只写一层，标签用逗号分隔。

## 工具条

- **阅读 / 看板 / 关联网络**：三种查看同一批搜索结果的方式。
- **数据目录**：打开本机数据目录，直接查看 Markdown、索引和配置。
- **刷新**：重新扫描外部编辑器改过的文件。删除或新增 Markdown 后也可以点它。

## 阅读视图

正文里的 `[[笔记ID]]`、`[[笔记ID|显示文字]]` 或 `[[标题]]` 会变成可点击链接。阅读页底部列出反向链接；右上角的编辑和删除按钮会带着当前版本号操作，避免覆盖别人刚改过的内容。

删除笔记时，其他笔记中指向它的链接会被清理成普通文字，代码块里的示例保持原样。删除不可撤销，确认框会提示受影响的链接数量。

## 关联网络

拖动空白处平移，滚轮缩放，拖动节点调整布局；悬停看标题，点击节点打开笔记。顶部可以放大、缩小、适应视野和暂停布局。图只显示当前筛选结果，范围太大时请先用搜索或标签缩小。

## 键盘快捷键

| 快捷键 | 作用 |
| --- | --- |
| `/` | 聚焦左侧搜索框 |
| `Ctrl + N` | 新建笔记 |
| `?` | 打开使用指南 |
| `Esc` | 关闭对话框 |
