# 让知识在链接之间生长

这里是 Link Garden 的默认指南库。每一篇笔记都是一个普通的 Markdown 文件，分类只有一层，标签保持扁平，双向链接来自正文里的显式引用。

## 3 分钟上手

1. **找内容**：在左侧搜索标题、正文或标签；也可以点分类、标签筛选。结果显示原文片段和行号。
2. **读笔记**：点击左侧笔记打开阅读视图；正文里的 `[[链接]]` 可以直接跳转。
3. **写笔记**：点右上角「＋ 新建笔记」，填写标题和正文。标题可以随时改，链接使用稳定的笔记 ID。
4. **建立联系**：在正文写 `[[quick-tour]]`、`[[quick-tour|界面速览]]` 或 `[[界面速览]]`，目标笔记会自动出现反向链接。
5. **管状态**：切换到「看板」，按「待整理 / 进行中 / 已完成」查看和移动卡片。
6. **看全局**：「关联网络」把当前筛选结果画成图；拖动空白平移，滚轮缩放，点击节点阅读。

## 删除笔记

阅读视图里有「删除笔记」。确认后：

- 对应 `.md` 文件会从库目录删除；
- 其他笔记中指向它的 `[[链接]]` 会被清理，链接的显示文字保留为普通文本；
- 代码块和行内代码里的 `[[示例]]` 不会被改写；
- 操作不可撤销，建议先确认反向链接列表。

## 连接 Agent

打开「连接 AI」，复制全局注册指令交给 Agent。MCP 使用本地 stdio，不需要开端口，也不需要另外安装 Node.js。Agent 会先搜索、再按需读取，不会把整个库塞进上下文。
