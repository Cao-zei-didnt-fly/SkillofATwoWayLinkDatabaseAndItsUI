# 让知识在链接之间生长

这里的每一篇笔记都是一个普通的 Markdown 文件。

- **分类**只保留一层，方便快速归档。
- **标签**描述多个主题，无需嵌套文件夹。
- **双向链接**来自显式引用，例如 [[agent-interface|Agent 接口]]。
- **看板**按照状态组织笔记，可以直接更改卡片状态。

你可以在编辑器里写 `[[笔记ID]]`、`[[标题]]` 或 `[[笔记ID|显示名称]]`。目标笔记会自动显示反向链接。
