# 0.5 打包与接入说明

本版替代 0.3 的默认自动预写方案。面向 Windows 10/11 x64，无开机自启动、无托盘和系统服务。已在本机 Windows 11 验证，Windows 10 没有实机验证环境。

## 接入必经步骤

安装器的“Agent 自行全局注册与信任核验”为固定必选项。它生成本机 REGISTER-MCP.md，不再自动修改 Agent 的用户配置。应用“连接 AI”也优先提供必做指令，而不是声称写入就等于接入。

支持说明包括 Codex、WorkBuddy、CodeBuddy、Cursor、Claude Desktop、VS Code/Copilot、Cline。Agent 应使用各客户端原生注册方法或用户级全局配置。CodeBuddy 与 WorkBuddy 的目录、信任和权限设置独立；CodeBuddy 原生注册使用 --scope user。项目级配置可能遮蔽全局条目，需由 Agent 核验，不批量改写其他项目。

信任授权必须由客户端及用户正常完成。安装器不伪造信任、关闭沙箱或自动放行所有工具。报告应区分全局配置、客户端信任、握手和实际调用四个状态。应用自身的只读诊断只验证独立进程，不冒充其他客户端授权状态。

旧版接入管理和备份代码保留供解除 0.3 的旧记录；新的默认安装/接入路径不会调用它去预写配置。Agent 手动注册的条目不会自动认领，卸载时保留给用户在客户端清理。

## 图谱性能

物理仿真移到 Web Worker，低频传递坐标；拖动时暂停计算。主线程采用不取消已排队帧的合并绘制、批量点线、限制高倍缩放的标签数、四叉树命中检测、限制大图像素比例。后台线程不可用时降级为可交互的静态布局，避免把高开销仿真退回界面线程。

性能检查使用 1000 节点、3000 边，以及 1 倍/6 倍 CPU 节流的原生拖动输入，对比 0.3 绘制次数。结果在 dist/graph-performance.json；它是本机受控测量，不等于用户另一台电脑的保证帧率。

## 本地集中目录

首次安装优先 D:\Link Garden，不存在 D 盘时使用 C:\Link Garden；可手动改目录。程序将 vault、索引、profile/session、integrations、logs、crash-dumps、tmp 集中到安装目录的 data，写入失败明确报错，不隐式退回 AppData。安装器取消 LocalAppData 的完整安装包缓存。

旧 AppData 中的笔记与部分设置首次复制迁移，同名冲突不覆盖，旧原件保留；记录在 data/.layout.json。升级和卸载只移除已知程序文件，保留 data 与用户根目录文件。客户端全局 MCP/skill 配置仍遵循客户端规定位置。
